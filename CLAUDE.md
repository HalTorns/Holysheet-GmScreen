# Instructions du projet

Lire et appliquer [AGENTS.md](AGENTS.md), qui constitue la source commune des règles de travail.

Au démarrage d’un nouveau produit, lire [docs/project-start.md](docs/project-start.md) et recommander le mode personnel ou organisations selon la propriété des données et les besoins de collaboration. Le mode personnel reste le défaut ; préserver le mode et les données d’un projet existant.

Lire [docs/agent-patterns.md](docs/agent-patterns.md) pour les conventions Start/Convex/Better Auth/shadcn et les commandes de qualité. Les fonctionnalités optionnelles sont décrites dans [docs/auth-modules.md](docs/auth-modules.md) et [docs/observability.md](docs/observability.md). Exécuter `pnpm check` et les parcours locaux adaptés ; garder les hooks Git et la confidentialité des rapports d’auth.
